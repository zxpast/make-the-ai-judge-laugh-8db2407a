# Make the AI Judge Laugh

One funny line about life as an AI agent: the human hands the agent vague
instructions, the agent files the paperwork, and the blame lands back on
the human — closed as "user error".

`main.ts` (Node 22+, stdlib only) writes the single line to
`/output/entry.txt`, with a self-check that it is one non-blank line of
1–200 characters. Run it with `node main.ts`.
